# Airline-Booking-System

A full-stack airline booking platform designed to demonstrate modern application development and infrastructure practices.

## Overview

This project provides an airline booking system with a web frontend, backend services, and containerised deployment using modern DevOps tooling.

## Technology Stack

- Frontend: Next.js, React, TypeScript
- Containerisation: Docker
- CI/CD: Jenkins
- Reverse Proxy: Caddy
- Version Control: GitHub

## Features

- User-friendly booking interface
- Containerised application deployment
- Automated builds and deployments through Jenkins
- Secure HTTPS routing with Caddy

## Deployment

The application is built into Docker containers and deployed automatically through a CI/CD pipeline triggered from the Git repository.
